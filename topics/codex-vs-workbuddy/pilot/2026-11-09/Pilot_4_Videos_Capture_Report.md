## 现在可以交给 Gemini 的材料

对每条视频，本地包可用：

1. `source.md` — 链接、作者、时长、指标、声明、观看限制  
2. `transcript.md` — **分层**：烧录字幕候选 / 画面文字 / 平台「章节要点」（非口播）/ 研究者推断  
3. `visual_timeline.md` — 0–3s、3–10s、中段、结尾结构  
4. `comments.md` — 代表性评论 + 分类标签 + 采集方法  
5. `evidence_manifest.md` / `capture_gaps.md` — 证据清单与缺口  
6. `assets/` — 关键帧截图（非完整影片）  
7. **原 Douyin URL** — 若需完整运动画面+声音，必须自行打开页面播放

详见同目录 `Gemini_Handoff.md`。

## 仍然缺失

1. **无本地视频/音频文件**（四条皆无 `*.mp4` / CDN 媒体落盘）。  
2. **口播未耳朵核验**：即便部分视频播放器 unmute UI 成功（如 A02 volume 100），本采集环境仍无法确认实际听到语音。  
3. **未找到平台「完整文稿」面板**可复制导出。  
4. **B01 烧录字幕可读性弱**，口播层证据显著薄于另外三条。  
5. **评论非穷尽**：实收 40 / 75 / 47 / 42，对应显示 352 / 213 / 89 / 215；嵌套回复多数未全展开。  
6. **评论排序「最热」** 多数会话未成功切换或未找到可用控件。  
7. Gemini **不能**仅凭本包截图+字幕还原完整音画；须依赖原 URL。

## 方法限制（明文）

- 无抖音官方连接器；仅官方网页。  
- 禁止 yt-dlp / 第三方下载器 / CDN MP4 抓取；未上传未经授权的完整第三方视频到公开 GitHub。  
- computerUse 采集环境无法核验可闻语音。  
- 「章节要点」仅为平台 AI 摘要，**不得**当作逐字口播。  
- 指标在会话中可能轻微跳动（评论数、分享数等）；以各 `source.md` / `comments.md` 记录值为准。
