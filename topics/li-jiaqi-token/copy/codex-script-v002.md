# 李佳琦卖 Token，买的到底是啥？

李佳琦，开始卖 Token 了。

一分钱买到的，到底是个什么东西？

先看你平时怎么用 AI。你把一周的工作记录发给它，让它帮你写周报。AI 处理文字时，会把内容拆成一个个小块，这些小块就叫 Token，中文叫词元。

你发过去的工作记录，要拆成 Token；它写出来的周报，也由 Token 组成。不同模型拆分的方式不同，一块可能是一个字，也可能是一个词的一部分。

有了这个单位，就能统计模型处理了多少内容。一些 AI 服务会按输入和输出的 Token 数量收费，卖给用户的产品也可以做成会员月卡，或者按积分使用。

这次李佳琦直播间一分钱上架的，就是千问办公的个人会员月卡。买到的是一个月的办公软件会员权益。活动期间，付费个人会员在标准模式下处理文档、制作 PPT 等，可以不限量使用；涉及图片、音视频的任务，仍要按规则消耗积分。

刚开始用 AI，可以先拿手头一份文档，让它提炼三条重点，再自己对照原文检查结果。
