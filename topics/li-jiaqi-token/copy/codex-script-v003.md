# 李佳琦卖的 Token，到底是什么？

大家熟悉的李佳琦，最近在直播间开始带货 Token 了。这个 Token 到底是什么，又能拿来干什么？

Token 的中文叫词元。AI 处理文字的时候，会先把一段话拆成一个个小块，这些小块就叫 Token。一块可能是一个字，也可能是一个词的一部分，不同模型的拆法还不一样。

那 Token 有什么用？

它主要用来统计 AI 处理了多少内容。比如你把一周的工作记录发给 AI，让它帮你写周报。你发过去的文字，会算输入的 Token；它写出来的周报，会算输出的 Token。有些 AI 服务，就是按输入和输出的 Token 数量来收费的。

所以你平时看到的“送多少 Token”，通常是在说这项 AI 服务给你多少使用额度。

那李佳琦这次卖的，又是什么形式？

他卖的是千问办公的个人会员月卡，当晚的活动价是一分钱。就跟平时买软件会员一样，你买到的是一个月的会员使用权益。

这张卡在活动期间可以畅用标准模式，用来写文档、处理数据、做 PPT；生成图片、音视频等任务，另外按规则消耗积分。
