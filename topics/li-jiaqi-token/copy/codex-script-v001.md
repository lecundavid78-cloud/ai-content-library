# 李佳琦卖的 Token，到底是什么？

李佳琦直播间，连 Token 都开始卖了。这东西到底是什么，买回来能干什么？

我对了一下报道和千问办公的官方说明。当晚卖的是千问办公的个人会员月卡。新京报报道的福利价是一分钱，可以用来写文档、处理数据、做 PPT。

那怎么又叫卖 Token 呢？

先看一个最普通的场景。你发给 AI 一份会议记录，让它帮你整理成纪要。AI 处理这些文字时，会把内容拆成一个个小块，这些小块就叫 Token，中文叫词元。

一块可能是一个字，也可能是一个词的一部分。不同模型拆分的方式不同，不能固定按一个字算一个 Token。你发过去的会议记录，以及 AI 生成的纪要，都会涉及 Token。

有了这个单位，就能统计模型处理了多少内容。一些 AI 服务会按输入和输出的 Token 数量收费。普通用户更常接触到的，是软件会员或者积分，按产品的规则使用。

回到这次直播。买到月卡后，你获得的是这款办公软件一个月的会员权益。官方说明，活动期间，付费个人会员可以在标准模式下处理文档、制作 PPT 等；涉及图片、音视频的任务，仍要按规则消耗积分。

所以，新闻里“半小时卖出约两万亿 Token”的说法，指的是这批月卡对应的合计额度，不能理解成用户已经把这些额度用完了。

以后再看到“卖 Token”，先看清买到的是哪款产品、能用哪些功能。对刚开始用 AI 的人，可以拿一份现成的文档，让它帮你提炼重点，再自己检查结果。从手头的一件小事开始，就容易明白 AI 能帮你做什么。
