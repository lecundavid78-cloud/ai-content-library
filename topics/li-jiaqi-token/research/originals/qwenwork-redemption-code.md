# 兑换规则

### 兑换码类型

- 目前有 4 类兑换码类型，个人用户账户支持领取以下兑换码：
  1. 个人积分兑换码
  2. 个人基础版兑换码
  3. 个人标准版兑换码
  4. 个人高级版兑换码

### 兑换规则

- 千问办公积分，兑换需注册千问办公账号；仅支持千问办公内使用
- 个人版兑换码不支持充值到企业账号
- 个人标准版支持领取个人标准版兑换码，权益时长累加
- 个人标准版和个人高级版不支持同时兑换和领取
- 兑换时登陆的账号，即为积分归属的账号；积分不支持多账号通用
- 积分与订阅权益有效期，请以活动官方说明为准
- 本产品属于虚拟权益产品。一经充值，不支持退换；请核对充值账号无误后，再兑换

### 到账查询

**积分兑换到账查询**：在独立端，登录个人版账号。左下角点击头像选择【设置】，点击【订阅和用量】；权益生效可能有短时间延迟，请耐心等待。

| 步骤 1                                                                                                                                         | 步骤 2                                                                                                                                        |
| -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 点左下角头像，选择【设置】，在【订阅和用量】-【我的积分】，即可检查权益是否生效                                                                                                     | 点击【明细】，即可查看积分具体获得明细                                                                                                                         |
| ![订阅和用量](https://g-adoc.alcasset.com/sync/maas_docs/qwenwork-cn/master/cn/media/zh/images/redemption-code-bd9725e00ac5f324_36c5478bdd13.png) | ![积分明细](https://g-adoc.alcasset.com/sync/maas_docs/qwenwork-cn/master/cn/media/zh/images/redemption-code-475c0bc3a99f1092_36c5478bdd13.png) |

**订阅兑换到账查询**：在独立端，登录个人版账号。左下角点击头像选择【设置】，点击【订阅和用量】；权益生效可能有短时间延迟，请耐心等待。
