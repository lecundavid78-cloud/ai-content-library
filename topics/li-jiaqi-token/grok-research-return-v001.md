## 实际商品是什么

不是可提现虚拟货币，也不是百炼 API 按量 Token 包。  
交叉官网后，实质是 **千问办公（QwenWork）个人基础版会员月卡权益**（兑换码/虚拟会员）：官网个人基础版 **28 元/月**，直播福利价媒体称 **0.01 元**。权益核心是官网写明的 **标准模式畅用**（文档/数据/PPT 等日常办公）+ **每月基础积分 500**（图/音视频等大算力按积分结算）；另有限时新用户/月初赠送积分规则。兑换通用流程见官网兑换指引；本场是否「仅新用户、限购1、12月30日前激活」等细则目前多见于第三方优惠站，**未用天猫官方商品页核实**。

**禁止误读：** 勿把「对应/发放的万亿 Token」写成用户已消耗量；勿用 2万亿÷10万 推定每份承诺 Token。

## Token 该怎么跟小白讲

采用阿里云官方表述：Token（词元）是大模型处理文本的基本单位，可以是词、子词或字符，取决于分词器；**输入和输出都会计**。可用「模型按自己的分词方式计份」作比喻，并立刻说明：它计量的是处理量，不是人民币余额，也不是通用可转卖货币。本次直播是把 **会员权益** 用 Token 叙事卖给大众，前台规则以千问办公会员/积分为准，勿与开发者按量账单混为一谈。不要写「一个汉字=一个Token」。
