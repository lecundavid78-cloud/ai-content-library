## 2. 商品实质与使用条件

### 2.1 实际商品是什么（核心结论）

**消费者实际买到的是：千问办公（QwenWork）个人会员月卡 / 个人基础版月卡权益（兑换码形态的虚拟会员），不是“可任意提现的虚拟货币 Token”，也不是阿里云百炼 API 的按量 Token 资源包。**

依据：
- 媒体统一称商品为“千问办公个人会员月卡”，直播价 **0.01 元**，并称原价 **28 元**（28 元与官网个人基础版月价一致）。来源：新京报、澎湃、时代周报等（媒体）；官网个人基础版 **28元/月**（官方）。
- 官网个人版权益表：个人基础版含「标准模式畅用」、每月基础积分 **500** 等。来源：`https://qwenwork.cn/docs/benefits/personal`（官方）。
- 官网兑换指引：存在「个人基础版兑换码」类型；虚拟权益一经充值不支持退换。来源：`https://docs.qwenwork.cn/redemption-code` / `https://qwenwork.cn/docs/benefits/redeem-code`（官方）。

## 3. Token 概念解释素材（给小白，非口播稿）

### 3.1 官方定义（优先引用）

1. **阿里云信息查询服务术语表**（`document_detail/3000052`）：  
   「词元（Token）也叫令牌，是大语言模型处理文本的基本单位，它可以是一个单词、子词、标点、字符，具体取决于所使用的分词器（Tokenizer）。LLM 的输入和输出均以 Token 序列形式进行处理……」  
   注意：该页属 IQS 术语表，需与百炼/ARMS 交叉。

2. **阿里云 ARMS《Token分析》**：  
   「在大模型应用中，Token 是文本处理的基本单位，用于表示模型输入和输出的最小语义单元。Token 可以是一个单词、一个子词（subword）或一个字符，具体取决于模型的分词方式（Tokenizer）。」

3. **阿里云百炼模型价格/用量说明（交叉）**：模型调用常按**输入 Token、输出 Token**分别计价；实际用量以接口统计为准；不同模型分词器不同。

### 3.2 必须遵守的表述边界

- **不要写**「一个汉字 = 一个 Token」。
- **不要把** AI Token **直接说成**可流通虚拟货币/比特币类资产。
- **不要说**「所有 AI 都必须先买 Token」。
- 不同模型、不同产品的额度**不可当成通用余额**。

### 3.3 简单情景示意（无精确数字）

情景：用户在对话框输入一段工作需求（例如“帮我把三点会议纪要整理成周报提纲”），模型先读入这段文字（**输入侧**消耗 Token），再生成回复（**输出侧**也消耗 Token）。  
在千问办公会员里，用户前台看到的往往是「能否继续畅用 / 积分是否足够」，而不是开发者控制台上的 Token 账单；直播把会员叫成“Token”，是在用行业计量词做大众传播，**不等于**用户钱包里出现了一笔可提现余额。

若未来文案需要精确 Token 数：必须注明模型名、分词器/接口返回字段与测试原文；本包**不提供未实测数字**。

### 3.4 比喻素材（一句边界）

比喻：Token 更像「模型吃饭的口感计量」——你说的话和它回的话都要按它的分词方式计份。  
边界：**它计量的是模型处理量，不是人民币余额，也不是可以转给别人的通用点数。**
