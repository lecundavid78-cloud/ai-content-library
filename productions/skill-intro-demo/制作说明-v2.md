## 0. 怎么看

| 方式 | 操作 |
|---|---|
| **直接看（推荐）** | 双击 `demo-v2/index.html`，打开约 0.5 秒后自动播放。单文件 322KB，字体、样式和脚本全部内联，不需要联网 |
| 看视频 | `demo-v2/preview.mp4`（1920×1080，30fps，35.0s，无声）。它由同一份 HTML 逐帧渲染，和网页画面一致 |

也支持 URL 参数：`?t=15.6` 定格到某一秒，以及 `?guides=1`、`?subs=0`、`?slot=key`、`?loop=1`。

## 1. 从参考视频里学到了什么（以及我采用了什么）

我把 167 秒的参考片按每 2 秒一张拼成联系表看了一遍，又在几处转场按每秒 4 帧逐帧看了动作，还从画面里取了实际颜色。
有一点要说明：**我没有逐句听写它的口播音频**，下面关于节奏的判断都来自画面。

它让人舒服、愿意看下去，我认为主要靠这 7 点：

| # | 参考片的做法 | v2 怎么用 |
|---|---|---|
| 1 | **深、浅两种舞台交替**：开场和数据段用炭黑（实测约 `#1A161B`，不是纯黑），讲解段换成近白（约 `#FCFCFC`）。整片明暗有起伏，眼睛不累 | S01 用炭黑 `#19181C` 抛出痛点；S02 起慢慢亮成暖白 `#FAFAFA` 开始讲解。舞台色由场景的 `stage: 'dark' \| 'light'` 决定，切换由引擎完成 |
| 2 | **颜色极少**：黑、白、金（约 `#E4B454`），加一个紫（约 `#7854E4`）标关键词，红色只在「不行 / 错」的时候出现。它自己的 SKILL.md 截图里也写着「颜色只用金、红、黑」 | 深舞台只用**金** `#E8B54F`，浅舞台只用**紫** `#7B5CF0`，一屏最多出现一种强调色。红色 `#E5484D` 全片只出现一次，就是「第 3 次漏说了配色」 |
| 3 | **一屏一个意思，留白很多**：一句大字，最多再加一组卡片，其余地方都空着 | 每个场景只有一句主句，加一张主卡或一排方块。大字从 v1 的 168px 降到 76–112px，靠留白拉开层级，不靠字号去「砸」 |
| 4 | **动作轻、慢**：卡片带一点纵深从下方立起，文字逐字浮现，场景之间用模糊溶解衔接。它的 SKILL.md 里明确写着「不用：轰炸动效（砸下、震屏、闪白）」 | 去掉 v1 的 `slam`（砸下）、`shake`（抖动）和行军蚁虚线。换成 `in`（上浮 + 去模糊，650ms）、`tilt`（卡片带 22° 纵深立起，850ms）、`type`（逐字，每字间隔 55ms）、`fill`（虚线占位行被逐行填满）、`mark`（紫色荧光笔划过）。只有 44px 的小对勾 / 叉保留了一点轻微回弹 |
| 5 | **节奏稳**：它写的是「舞台每 4–6 秒换一次」；每屏里元素逐个出现，然后停住让人看 | 6 个场景，每个 5–6 秒，引擎会自动检查每屏停留时间是否在 4.5–6.5 秒之间。另外每个场景都有一个肉眼几乎看不出的「镜头呼吸」（整体缓慢放大 1.8%），画面停住时也不会显得死 |
| 6 | **字幕克制**：黑底小圆角条、白字、单行，放在下方居中 | 照这个做：黑底条（92% 不透明）、34px 白字、单行，在主视觉列底部居中。字幕不使用强调色 |
| 7 | **标注压在卡片边上**：黑色胶囊标签、小圆形对勾 / 叉徽标，有一点叠层感 | S05 的「Skill 的名字 / 决定 AI 什么时候用它」两个黑胶囊压在白卡右边缘上；S01、S03、S04 的卡角用小圆徽标收尾。章节角标学了它「0 1 画面」的数字方块写法 |

**没有照搬的部分**：它的 Logo、财经题材、真实新闻画面、人物和文案都没有用。它在章节名和大字上用的是一款紧缩的粗标题字体，我试了开源的得意黑（Smiley Sans，可商用），实测字重偏细、还是斜体，放在这里不如 Noto Sans SC 900 稳，所以 v2 没有引入新字体。

## 3. 口播框：位置和尺寸都没变

- 竖屏 9:16，**280 × 498，左上角 (96, 528)**，右下角 (376, 1026)，和 v1 完全一致，后期素材不用重新对位。
- 禁区不变：口播框向上、向右各外扩 40px。所有卡片、大字、胶囊、方块和徽标都在主视觉列 x 456 → 1824（中心 x = 1140）以内，引擎会自动检查，当前 0 条违规。

## 4. 和 v1 相比改了什么

| 维度 | v1 | v2 |
|---|---|---|
| 舞台 | 全程近黑 `#070709` + 星尘 | 炭黑 ↔ 暖白交替；去掉星尘，只保留极淡的暗角 |
| 强调色 | 荧光绿 `#B8FF01` 胶囊 + 黄色虚线框 + 蓝 + 红 | 金（深舞台）/ 紫（浅舞台），一屏一种；红色只出现一次 |
| 大字 | 168px、900 字重、`-6deg` 斜切、绿色辉光 | 76–112px、900 字重、不斜切、不发光，层级靠留白拉开 |
| 动效 | 弹性缩放 0.25–0.35s、砸入、抖动、虚线框行军蚁 | 上浮 + 去模糊 0.55–0.85s、逐字打出、纵深卡片、占位填满、荧光笔；场景之间模糊溶解 |
| 文档 | 出现 1 秒后压暗，再「提起」关键行 | 不给大段可读正文：要读的只有 1–2 行，其余用骨架条表示，从根上避免和字幕抢视线 |
| 字幕 | 无底色白字 + 阴影 | 黑底小圆角条（学参考片） |
| 节奏 | 3 个镜头，16.8s，每屏约 5s 但内部很密 | 6 个镜头，35s，每屏 5–6s，元素逐个出现后会停住 |
| 校验 | 文档 1 秒压暗、大字 ≤10 字、禁区、安全区 | 每屏停留 4.5–6.5s、主句 ≤12 字、字幕不重叠、禁区、安全区，并额外做了导出视频的亮度检查（见第 6 节） |

### v1 的 7 个待确认问题，v2 的选择（按「看起来舒服」优先）

1. **口播框形态** → 保持竖屏 280×498，位置不变。主视觉列整体右移的构图，在大留白的版式下并不拥挤。如果你的口播素材是横屏拍的，仍建议改成 400×225（只需改 `tokens.css` 里的 4 个数）。
2. **字幕** → 继续由 HTML 渲染，样式改成参考片那种黑底条。如果你习惯在剪映里出字幕，用 `?subs=0` 导出即可。
3. **字体** → 用 Noto Sans SC 900（即思源黑体 Heavy），不换阿里妈妈数黑体。舒服优先，数黑体太方、太「工业」。
4. **名牌「阿泽」** → 保留，改成白底黑字的小胶囊。设 `Studio.config.slot.name = ''` 即可关闭。
5. **节奏** → 改成参考片的「每屏 4–6 秒」，由引擎自动检查。
6. **绿 + 黄撞色** → 已取消，整套配色改为黑、白、金、紫。
7. **星尘** → 已去掉，改成极淡的暗角或亮角，让画面有一点深度，但不会动。

## 5. 工程结构（v2）

```
skill-intro-demo/
├─ refs/                      参考视频与说明（只读）
├─ src/ + demo/ + 制作说明.md  v1（保留不动）
├─ src-v2/                    ← v2 源码，以后改这里
│  ├─ index.html              开发入口；<script> 的顺序就是时间轴顺序
│  ├─ styles/tokens.css       视觉规范：舞台色、墨色、金、紫、字号、动效时长、口播框
│  ├─ styles/base.css         舞台、深浅背景、字幕条、章节数字方块、口播框、参考线、播放器
│  ├─ styles/components.css   .c-hero .c-title .c-lead .c-pill .c-card .c-row .c-skel .c-badge .c-tile .c-mark
│  ├─ styles/scenes.css       布局原语 .l-* + 各场景坐标（用 #场景id 前缀隔离）
│  ├─ js/engine.js            确定性时间轴、柔和动效预设、深浅舞台切换、镜头呼吸、校验
│  ├─ js/components.js        口播框、系列标记、逐字拆分、图标、播放器
│  └─ js/scenes/s0N-*.js      一个镜头一个文件
├─ demo-v2/                   ← 构建产物（index.html / preview.mp4 / stills/）
└─ tools/build.py · render.mjs  v1、v2 共用（新增 --src/--out 参数和 OUT 环境变量，默认行为仍是 v1）
```

新增一个镜头，例如 `src-v2/js/scenes/s07-xxx.js`：

```js
Studio.scene({
  id: 's07-xxx', stage: 'light',                 // 'dark' | 'light'，和上一场景不同时自动做 1.4s 渐变
  chapter: { no: '04', title: 'AI 怎么调用 Skill' },
  duration: 5.5,                                 // 4.5–6.5s
  html: `
    <div class="l-col">
      <span class="c-pill">先看<em>目录</em></span>
      <div class="c-hero c-type">按需<em>加载</em></div>
    </div>`,
  cues: [
    { at: 0.3, sel: '.c-pill', fx: 'in' },
    { at: 0.8, sel: '.c-hero', fx: 'type' },     // 带 .c-type 的元素会被自动拆成逐字
  ],
  subs: [{ from: 0.3, to: 5.3, text: '一句字幕，单行' }],
});
```

可用的动效：`in` / `soft` / `tilt` / `type` / `fill` / `mark` / `badge` / `recede` / `out`。这些预设都只定义在 `src-v2/js/engine.js` 顶部的一个地方，要调整全片节奏只改那里。

常用命令：

```bash
python3 tools/build.py --src src-v2 --out demo-v2/index.html   # 子集化字体并打包（需要 fonttools；有 brotli 时输出 woff2）
OUT=demo-v2 node tools/render.mjs check                         # 时长、lint、口播框坐标、外部引用
OUT=demo-v2 node tools/render.mjs stills 5 15.6 27.8            # 导出静帧（可加 --guides / --slot=key / --nosubs）
OUT=demo-v2 node tools/render.mjs video 30                      # 逐帧导出 MP4（--slot=key 出抠像版）
```

字体和 v1 相同：Noto Sans SC（可变字重 100–900，与思源黑体同一套字形）和 JetBrains Mono，均为 SIL OFL 1.1，原文件和授权在 `assets/fonts/source/`。**改了文案后必须重跑 `build.py`**，否则新增的字会回落到系统字体。

## 7. 已知问题

1. **预览成片没有声音**。参考片之所以舒服，配乐和口播语速占了很大比重，而这条样片只能看画面气质。时间轴目前是我按口播稿估的，没有对齐真实语音。
2. 炭黑 → 暖白的切换虽然已经放慢到 1.4 秒，但亮度跨度本身很大（平均亮度从约 38 到约 217）。在暗环境下看可能还是会觉得「亮了一下」。如果你介意，可以把浅舞台压暗到 `#F2F2F0`，或者整期只在章节切换时换舞台。
3. 浅舞台上的口播框占位是一块深色卡，在没有真人画面的样片里会比较抢眼。嵌入真实口播后会好很多。
4. 标题字体比参考片「方、宽」一些：参考片用的是紧缩粗标题体，这里是 Noto Sans SC 900。
5. `fill` 动效里卡片行的底色写死为 `rgba(42,41,47)`，和 token `--card-dark-2` 是重复定义，以后改卡片颜色时需要两处一起改。
