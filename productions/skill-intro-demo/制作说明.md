## 2. 口播预留框

| 项 | 数值 |
|---|---|
| 形态 | 竖屏 9:16 小窗（按你的要求先做竖屏） |
| 尺寸 | **280 × 498 px**（280 × 16/9 = 497.8，取整为 498） |
| 坐标 | 左上角 **x = 96, y = 528**；右下角 **(376, 1026)** |
| 安全边距 | 左边和底边正好贴在 5% Title Safe（96 / 54）上，不越界 |
| 圆角 / 描边 | 16px / `1px solid rgba(255,255,255,0.15)`，与卡片规范一致 |
| 禁区 | 口播框向上、向右各外扩 **40px**（x < 416 且 y > 488）。所有主视觉元素都不得进入这一区域，由引擎自动检查 |
| 主视觉区 | x **456 → 1824**（宽 1368，中心 x = 1140）。大字、卡片和字幕都以这一列居中，所以构图是「有意偏右」的，不会和口播框打架 |

占位框只画了取景角标、摄像机线框图标、「口播画面」字样和尺寸，**没有用任何人脸或照片**。左下角的「阿泽」名牌是可选组件（`Studio.config.slot.name = ''` 可关闭）。

合成用的两种导出模式：

- `?slot=key`：框内填纯绿 `#00FF00`，剪映 / PR / AE 直接做色键，口播画面放在下层（样例见 `demo/stills/t15.50_slot-key_nosubs.png`）
- `?slot=alpha`：框内透明，适合以后导出带 alpha 的序列

**如果改成横屏小窗**，我建议 **400 × 225（16:9）**，放在 x = 96, y = 747（底边对齐 1026）。这时禁区变矮（y > 707），主视觉区可以向左扩到 x ≈ 536 以上，上半屏还能横跨全宽。要改的只有 `tokens.css` 里的 `--slot-w / --slot-h`，以及 `--main-x` 的算式。

## 3. 视觉规范（已落地为 `src/styles/tokens.css`）

### 颜色
| Token | 值 | 用途 |
|---|---|---|
| `--c-bg` | `#070709` | 背景（加极暗暗角 + 64 颗确定性随机的星尘，透明度 0.06–0.32，慢速漂浮） |
| `--c-card` | `#14151A` | 卡片底，描边 `1px rgba(255,255,255,.15)`，圆角 16px |
| `--c-green` | `#B8FF01` | 提炼大字、胶囊底（配纯黑 `#000` 文字）、章节号 |
| `--c-yellow` | `#FFD600` | 虚线框（`2px`，虚线 10/8）、重点注释 |
| `--c-blue` | `#38BDF8` | 文件夹、YAML 键名等结构类信息 |
| `--c-red` | `#FF4D4F` | 警告 / 错误（只在「出问题」时出现） |
| `--c-text` | `#F4F5F7` | 正文（不用纯白，避免刺眼），另有 62% / 38% 两级灰 |

### 字号层级（画布 px）
提炼大字 168（`--fs-hero`）› 次级大字 120 › 标题 56 › 字幕 38 › 卡片 26–30 › 标签 / 角标 18–22。
大字字重 900、`skewX(-6deg)`、字距 -0.02em、行高 1.08，并带极弱的绿色辉光；中文开启 `palt` 标点挤压，字幕关闭 `palt`，保证逗号和问号清楚可读。

### 动效
- 统一曲线 `cubic-bezier(0.22, 1, 0.36, 1)`，入场和强调 250–350ms，没有慢淡入淡出
  - `pop` 卡片 / 胶囊：scale 0.86→1，300ms
  - `slam` 大字：scale 1.42→1，320ms（从大到小砸入）
  - `rise` 列表行：上推 26px，280ms
  - `wipe` 注释：左→右擦出，300ms
  - `dim` 文档压暗：opacity 0.25 + blur 2px，250ms
  - `out` 出场：250ms
- `draw` 虚线框：SVG mask 的 `stroke-dashoffset` 1→0，400ms，**沿路径画出**虚线框。画完后黄色虚线以 1.4s 一圈的速度「行军蚁」微动，让定格画面也有呼吸感
- 场景切换：上一场景用 250ms `out` 出场，下一场景元素立刻弹入，没有黑场和交叉溶解

### 铁律（引擎自动校验）
1. 凡是 `.c-doc`（可读文档），出现后 **≤1.0s 必须 `dim`**
2. 文档处于可读状态的这段时间里，**不允许出现字幕**（S01 0.15–1.15s、S03 12.8–13.75s 字幕会让位）
3. 提炼大字 `.c-hero` **≤10 字**
4. 卡片、大字、胶囊、芯片、标签都不得进入口播禁区，也不得越出安全区

如果违规，预览页右上角会出现红色 LINT 提示，`node tools/render.mjs check` 也会列出来。

## 4. 字体来源（全部内置，无 CDN）

| 用途 | 字体 | 来源 / 授权 | 项目内位置 |
|---|---|---|---|
| 中文 / 大字 | **Noto Sans SC 可变字重 100–900**（与思源黑体是同一套字形，Heavy = 900） | Google Fonts 仓库（github.com/google/fonts），SIL OFL 1.1，可商用 | 原字体：`assets/fonts/source/NotoSansSC[wght].ttf` + `OFL-NotoSansSC.txt` |
| 等宽 | **JetBrains Mono 可变字重 100–800** | 本机系统字体副本，SIL OFL 1.1 | `assets/fonts/source/JetBrainsMono[wght].ttf` + `OFL-JetBrainsMono.txt` |

- `tools/build.py` 会扫描 `src/` 里实际用到的字（约 600 字），子集化为 `src/fonts/skill-sans.woff2`（177KB）和 `skill-mono.woff2`（34KB），再以 base64 内联进 `demo/index.html`，所以整个演示只有一个文件（334KB）
- 本机没有阿里妈妈数黑体，所以没有使用。它也是免费可商用的，如果你更喜欢它的字形，放进 `assets/fonts/source/` 后改 `build.py` 里的 `FONTS` 即可
- 回退链：`SkillSans → Source Han Sans SC → Noto Sans CJK SC → PingFang SC → 微软雅黑`
- ⚠️ **改了文案一定要重跑 `build.py`**，否则新加的字会回落到系统字体

## 5. 工程结构与长期复用

```
skill-intro-demo/
├─ 口播稿.md / 口播稿.docx
├─ 制作说明.md                 ← 本文件
├─ assets/fonts/source/        ← OFL 原字体 + 授权（子集化的来源，勿删）
├─ src/                        ← 唯一需要手改的地方
│  ├─ index.html               ← 开发入口（可直接打开）；场景顺序 = <script> 顺序
│  ├─ styles/
│  │  ├─ tokens.css            ← 视觉规范：颜色 / 字号 / 动效 / 安全区 / 口播框（真值来源）
│  │  ├─ base.css              ← 舞台、背景、字幕、章节角标、口播框、参考线、播放器
│  │  ├─ components.css        ← .c-card .c-pill .c-tag .c-hero .c-frame .c-doc .c-lifted .c-tree .c-chip
│  │  └─ scenes.css            ← 布局原语 .l-* + 各场景坐标（#场景id 前缀隔离）
│  ├─ js/
│  │  ├─ engine.js             ← 确定性时间轴：fx 预设 / seek / 播放 / 铁律 lint
│  │  ├─ components.js         ← 口播框、虚线框注入、提起行、星尘、图标、播放器
│  │  └─ scenes/sNN-*.js       ← 一个镜头一个文件（只写 HTML 结构 + cues + subs）
│  └─ fonts/                   ← build.py 生成的子集字体
├─ tools/
│  ├─ build.py                 ← 字体子集化 + 打包成单文件 demo/index.html
│  └─ render.mjs               ← 本机 Chrome 无头逐帧渲染：静帧 / MP4 / 校验报告
└─ demo/                       ← 构建产物（勿手改）
   ├─ index.html  preview.mp4  stills/
```

### 场景模板（新增一个镜头）
```js
// src/js/scenes/s04-xxx.js
Studio.scene({
  id: 's04-xxx',
  chapter: { no: '03', title: 'SKILL.md 写了什么' },   // 相邻同章节自动合并，不重复入场
  duration: 5.0,                                         // 秒
  html: `
    <div class="c-card c-doc doc">…可读正文…</div>      <!-- 正文必须用 .c-doc，lint 才会盯 -->
    <div class="l-col"><div class="c-hero"><span class="skew">提炼大字</span></div></div>`,
  cues: [                                                // at = 相对本场景的秒数
    { at: 0.10, sel: '.doc',   fx: 'pop' },
    { at: 1.10, sel: '.doc',   fx: 'dim' },              // ≤1s 压暗
    { at: 1.20, sel: '.c-hero', fx: 'slam' },
    { at: 1.60, sel: '.c-hero .c-frame', fx: 'draw' },
    { at: 2.00, sel: '.steps > *', fx: 'pop', stagger: 0.08 },
  ],
  subs: [{ from: 1.2, to: 4.8, text: '字幕一行，别超过 20 字' }],
});
```
然后在 `src/index.html` 里加一行 `<script src="js/scenes/s04-xxx.js"></script>`，跑 `build.py` 即可。

可复用的组件和写法：
- 虚线框：任意元素加 `class="c-frame" data-pad="12"`，cue 写 `fx:'draw'`
- 提起行：文档里的某一行加 `data-lift="key"`，引擎会在原位置生成高亮副本，cue 选择器写 `[data-lifted="key"]`
- 动效只有一个出处：要调整全片节奏，改 `engine.js` 顶部的 `S.fx`；场景里只写动效名

### 常用命令
```bash
python3 tools/build.py                 # 子集化字体 + 打包（需要 fonttools；装了 brotli 就出 woff2，否则自动出 woff）
python3 tools/build.py --no-fonts      # 只打包
node tools/render.mjs check            # 时长 / lint / 口播框坐标 / 外部引用 / 已加载字体
node tools/render.mjs stills 1 3.5 8   # 指定秒数导出静帧；可加 --guides / --slot=key / --nosubs
node tools/render.mjs video 30         # 逐帧导出 MP4（需要 ffmpeg）；--slot=key 可出色键版
```
`render.mjs` 每次启动一个临时的无头 Chrome，用完立刻关闭并删除临时配置，**不会常驻开发服务器或占用端口**。
因为所有动画都由一个主时钟统一 seek，HTML 预览和导出的视频逐帧一致，做完整片时可以直接从这里出素材。

### 做完整片时的建议
1. 每个口播段落做 1–3 个场景文件，命名 `sNN-关键词.js`；完整片按章节拆分成多个入口（`ep-01.html` …），共用 `styles/` 和 `js/`
2. 时间轴最好对齐你的成片口播：拿到口播音频的分段时间后，把 `duration` 和 `subs` 换成真实的时间码（可以写一个从 SRT 导入的小脚本，我可以接着做）
3. 输出流程：`render.mjs video --slot=key` 得到 1920×1080 视觉层 → 剪辑软件里把口播视频垫在下层并色键 → 混音

## 7. 待你确认的问题

1. **口播框形态**：竖屏 280×498 会占掉左下大约 1/6 屏，主视觉因此整体偏右。如果你的口播素材是横屏拍的，改用横屏 400×225 画面会更开阔。用哪种？
2. **字幕谁来出**：演示里的极简字幕由 HTML 渲染。如果你习惯在剪映里自动生成字幕，我会默认 `?subs=0` 导出，只保留「字幕让位」的时间规则供你参考。
3. **字体**：现在用的是 Noto Sans SC 900（即思源黑体 Heavy）。要不要换成阿里妈妈数黑体（更方、更有「科技频道」感）？换的话请提供字体文件，或者允许我下载官方的免费版本。
4. **名牌**：口播框里的「阿泽」绿色名牌要保留吗？全程显示，还是只在片头出现？
5. **节奏**：现在每个镜头大约 5 秒，信息比较密，适合 1.1–1.2 倍语速。成片要严格按口播音频的时间码对齐吗？如果能给我一版口播音频或 SRT，我可以把时间轴直接改成从时间码驱动。
6. **配色细节**：规范里绿色大字配黄色虚线框，这版保留了这个组合。如果你觉得两种亮色同时出现太跳，可以把虚线框统一成绿色、黄色只留给注释文字，改动只有一个 token。
7. **星尘强度**：现在是「几乎察觉不到」的程度（64 颗，最高透明度 0.32）。如果投到手机上看几乎不可见，需要的话可以加强一点。
