### 与第一章的衔接

- **开头**：第一章最后 0.7s 是停顿（口播画面停在 83.50s 那一帧，卡片退场，舞台是浅色）。第二章从原片 83.50s 直接开始，不再额外加停顿，以免两段停顿叠成 1.4s。
  - 舞台同样是浅色，口播窗口位置、裁切完全相同；
  - 口播画面从第一章停住那一帧的下一帧接着走。对比第一章片尾帧和第二章首帧，PSNR 26 dB：除了章节角标，画面内容几乎一样；
  - 第一个字「Skill」在章内 0.16s 开口，标题在 0.10s 开始逐字浮现，章节角标「02 Skill 长什么样」在 0.10s 浮入。
- **结尾**：同第一章，177.09–177.15s 声音做 60ms 淡出，之后 0.7s 静音，口播画面停在 177.15s 那一帧，卡片在 93.90s 起整组退场。第三章从 177.15s 接着开始，这 0.7s 就是章与章之间的自然停顿。
- 拼接方式：两章编码参数相同，按顺序放进剪辑软件首尾相接即可；也可以用 `ffmpeg -f concat` 直接拼。

## 5. 沿用第一章 / v3 的方式

- `src-ch02/` 由 `src-ch01/` 的引擎、组件、tokens、base 样式复制而来（第一章那份没有改），只在本章副本里加了三处：
  - `fillLight`：浅色文档卡里的占位行被填满；
  - `restore`：从「退后」恢复；
  - 单个部分时长上限放宽到 75s。
- 本章版式写在 `src-ch02/styles/scenes.css`，两个部分写在 `src-ch02/js/parts/pA-folder.js` 和 `pB-skillmd.js`。
- 配色、字体、黑底字幕条、章节数字角标、中轴 960 + 对称安全列 416→1504、标题与字幕居中，全部和第一章相同。
- 两个部分都在浅色舞台，与第一章结尾衔接时背景不会跳。
- 合成：新增通用脚本 `tools/compose_chapter.sh <章号>`。它按 presenter.mp4 的时长自动算帧数，每 640 帧分一段渲染再无损拼接；名牌通过 `NAME_FADE` 环境变量可选。第一章的 `compose_ch01.sh` 保留不动。

复现：

```bash
python3 tools/align.py /tmp/ch01/full.json refs/用户口播文案.md --from 83.5 --to 177.15 --offset 83.5 --out src-ch02/js/timeline.js --marks "…"
ffmpeg -ss 83.5 -t 93.65 -i refs/用户口播视频.mp4 -vf "crop=540:960:282:14,setsar=1,tpad=stop_mode=clone:stop_duration=0.7" \
       -af "afade=t=out:st=93.59:d=0.06,apad=pad_dur=0.7" -t 94.35 … demo-ch02/media/presenter.mp4
python3 tools/build.py --src src-ch02 --out demo-ch02/index.html
OUT=demo-ch02 node tools/render.mjs check          # lint + 逐帧版式审计
bash tools/compose_chapter.sh 02                   # 分段渲染 + 合成 → demo-ch02/preview.mp4
```

## 7. 已知问题

1. **章节角标在接缝处会切换**：第一章结尾还显示「01 为什么需要 Skill」，第二章开头角标先消失，0.1s 后「02 Skill 长什么样」浮入，右上角也从「第 1 章」变成「第 2 章」。这是有意的章节切换提示；如果你希望连成一片时没有这个跳动，可以把右上角改成不带章号的「Skill 入门」。这样需要重新导出第一章，本轮没有动已交付的第一章。
2. **部分 B 较长（71s）**：它一直在同一张卡上变化，前后有 33 次变化，不会有停滞感。如果你更想在「两个必填项」和「操作步骤」之间换一张新卡，可以在 64.75s 处拆成两个部分。
3. Whisper base 模型对个别短词可能有 ±0.1s 的误差。觉得哪张卡早了或晚了，改对应 part 文件那一行的 `at` 即可。
4. 「做 PPT ?」芯片在改写前的宽度是按改写后的长文本预留的，所以右侧会多一点空白。
5. 同第一章：没有背景音乐和音效；网页版拖动进度条时视频会短暂缓冲，成片没有这个问题。

本轮只做了第二章，没有发布，也没有动 GitHub。
