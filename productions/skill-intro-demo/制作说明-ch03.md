## 5. 沿用前两章的方式，以及本章的改进

- `src-ch03/` 的引擎、组件、tokens、base、components 样式都从 `src-ch02/` 原样复制。本章只写了：
  - `styles/scenes.css`：版式，新增可复用的深色文件夹卡样式 `.fold`；
  - `js/parts/pA-extras.js`、`js/parts/pB-limits.js`；
  - `index.html`（由第二章的入口改出）。
- **渲染提速（本章首次使用）**：
  - `tools/render.mjs` 新增 `SHOT=jpeg`：视频分段用 JPEG(q95) 截图。实测每帧约 0.12s，PNG 约 0.19s；与 PNG 版输出的 PSNR 为 52.8 dB，平均亮度相同；
  - `tools/compose_chapter.sh` 新增 `PAR=3`（同时开 3 个 Chrome）、`SKIP_COMPOSE=1`（只渲染），以及「已存在且帧数正确的分段自动跳过」（命令被打断后直接重跑即可续上）。还修了帧数比较：JPEG 分段的 ffprobe 输出会带一个逗号，现在只取数字比较；
  - **实测：本章 2748 帧，5 段，3 路并行渲染 2 分 22 秒，拼接 + 合成 34 秒，合计约 3 分钟。** 第二章同样规模，逐段串行渲染用了 40 多分钟（含环境节流）。
- 复现：

```bash
python3 tools/align.py asr/口播全片-whisper-base.json refs/用户口播文案.md --from 177.15 --to 268.00 --offset 177.15 --out src-ch03/js/timeline.js --marks "…"
ffmpeg -ss 177.15 -t 90.85 -i refs/用户口播视频.mp4 -vf "crop=540:960:282:14,setsar=1,tpad=stop_mode=clone:stop_duration=0.7" \
       -af "afade=t=out:st=90.79:d=0.06,apad=pad_dur=0.7" -t 91.55 … demo-ch03/media/presenter.mp4
python3 tools/build.py --src src-ch03 --out demo-ch03/index.html
OUT=demo-ch03 node tools/render.mjs check
PAR=3 SHOT=jpeg bash tools/compose_chapter.sh 03
```

## 7. 已知问题

1. 部分 A 较长（67.8s），但一直在同一张卡上变化（26 条变化 cue），每次讲新文件夹时下方例子区原地换内容，不会停滞。
2. 「SKILL.md 只写：做到哪一步，去查 references/ 里哪份资料」这句注释字号较小（24px），是为了不和字幕抢视线；在手机上看会偏小。
3. Whisper base 对个别短词有 ±0.1s 的误差，要微调时改 part 文件里对应那一行的 `at`。
4. 同前两章：没有背景音乐和音效。
