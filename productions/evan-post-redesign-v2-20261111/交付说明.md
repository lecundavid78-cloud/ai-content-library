## 2. 看片后发现的具体问题

以下都来自四期成片的抽帧和旧模板图层规划的实测，不是只读代码的推断。

### 开头 1—3 秒
- 第 0 帧同时出现三样东西：题目面板、表达卡 1/7、四行字幕。面板上最大的字是考题题意「小时候学到的新技能」，不是故事看点；已确认的封面文案「谁在训练谁？」没有进片。
- 表达卡在**整句开始时**就弹出，不是说到这个词时。第33期「play fetch」的卡比口播早 2.75 秒；「by accident」早 2.7 秒，等于提前剧透了反转句的关键词。

### 常驻题目面板
- 面板 977×329 像素，全片 40 秒不动。按“不透明度超过 25% 的像素 × 显示时长”统计，旧版四期平均遮盖 **27%—30%** 的画面，其中题目面板一项约占一半。
- 面板里的英文原题是多行左对齐塞在居中块里，第32期三行尤其明显。

### 双语字幕
- 英文 49px、中文 39px（成片像素）；中文是浅灰色、且从不高亮。配置里没有任何一句用到 `zh_hl`，所以中文释义和英文重点短语在字幕里对不上。
- 弯引号被字体画成全角：第33期画面上是「I’ d」「She’ s」，中间有一个空格宽的缝。
- 中文按字数均分换行，会拆词：第33期「一屁股坐／在老鼠上」「玩具／老鼠」，第32期「追／问」，第30期行尾孤立的「边。」。第32期还有一行以冒号开头。
- 中文没有行数上限检查。
- 字幕底边固定、高度随行数变，所以英文第一行的位置在一行句和两行句之间上下跳。
- 第33期第12句「She brings it back every single time,」比实际开口早约 0.7 秒出现，把上一句的「on purpose.」在词尾瞬间切掉。原因是识别把句首词的起点粘到了上一句句尾。

### 七张表达卡
- **第30、31、32期各有一张卡时长为 0，成片里从未出现**：第30期「make mistakes」、第31期「curled up」、第32期「taken it personally」。原因是同一句里有两个表达时，前一张被后一张的起点截断。旧的“七卡齐全”检查只数图层个数，所以没拦住。我用图层规划和抽帧两种方式确认过（第32期 43 秒处高亮着 taken it personally，卡片却是 7/7）。
- 卡片固定在“全片最高字幕框”上方，第33期盖住爪子，第32期顶边压进下巴区域（卡顶 y=1077，自动估计的脸部框底 y=1096）。四期里没有发现直接盖住嘴的帧。
- 卡内「重点表达 3/7」标签 27px，手机上约 9.7pt，基本读不到。
- 第33期「on purpose」的卡在这个词说完的同一瞬间消失（卡 31.41—33.22 秒，词 32.71—33.22 秒）。

### 故事与道具
- 场景图里专门画的道具被字幕框盖住：第33期地板上的玩具老鼠正好在字幕框后面，只有句间空档才露出来；第30期的花盆和撒出的土、第32期的手机也类似。
- 四段故事的段落停顿、反转句，在画面上没有任何对应变化。

### 顺带发现的内容问题（我没有改，请你决定）
- 第30期确认英文首句是「Recently,I stopped…」，逗号后缺空格，画面上照样显示。
- 第31期 `subtitles.json` 的中文和 `chinese.txt` 有 4 处不一致（如「五点时，我已经」对「不到…我就」）。

## 3. 两个方案

两个方案共用同一套时间轴、分句、字体层级和开场/反转处理，差别只在“表达卡放哪”和“字幕要不要底板”。

### 共同的改法

**开场分时展示（取代常驻面板）**
1. 顶部一条小提示条全程在：`🐾 雅思口语 Part 2 · 情景练习｜小时候学到的新技能`（高 68px）。中途划进来的人也知道是什么题。
2. 0—约 2.5 秒：猫头上方一个奶油色气泡，写已确认的封面文案「谁在训练谁？」，小尖角指向猫。第 0 帧就在，不做淡入。
3. 原题英文在上方栏最早的空档展开一次（第33期 6.0—9.9 秒），时长按词数算（2 秒 + 0.22 秒/词，限 3.5—7 秒）。
4. 最后一句「She’s a natural.」时气泡回来一次，和开头呼应。

原题信息完整保留：标签和中文题意全程可见，英文原题完整展示一次。

**字幕**
- 英文 54px 粗体，中文 42px、改成暖白色。手机 390pt 宽下约 19.5pt / 15.2pt（旧版 17.7pt / 14.1pt）。
- 英文、中文各最多两行，都是硬检查。放不下先逐级缩字号（英 54→51→48，中 42→40→38），再放不下就拒绝出片并提示重新分句，不会出现三行或小字。
- “中线锚定”：英文从固定中线向上长，中文向下长。一行句和两行句切换时，英文末行和中文首行的位置不动。
- 英文断行按词，避开把 a / the / to / my 这类词留在行尾，优先在标点后断；重点短语不拆；标点不会落到行首。中文优先在标点后断，其次在「的、了、把、就」这类边界断，不拆释义和英文词；自动在非标点处断行的句子会在检查报告里列出来让你看一眼，也可以在稿里用 `\n` 指定。
- 重点短语在**说到它的那一刻**才从左到右刷上黄色，中文里对应的释义同时变黄。字幕本身就能看出“这个英文 = 这个中文”，不必去读卡片。
- 弯引号只在画面上换成直引号（SRT 仍是确认稿原文）。
- 烧录字幕和 SRT 用同一条展示时间轴。规则：比开口早 0.08 秒出现；句间空档小于 0.45 秒直接接上；否则多留 0.35 秒；确认稿的空行（段落）之间强制留至少 0.22 秒干净画面；句首被识别粘连的用静音检测修正（第33期修了 1 处）。

**表达卡**
- 按词级时间出现（提前 0.12 秒），理想停留 3.2 秒。
- 每张卡有“最短可读时间”（0.6 秒 + 4 词/秒 + 11 字/秒）。如果下一张来得太快、上一张读不完，两张**同屏并排**而不是截断。零秒卡在结构上不可能再出现，检查也会拦。
- 七个小圆点表示进度，取代读不清的「重点表达 3/7」。
- 卡片上的英文用和字幕相同的黄色记号笔样式，靠颜色把两处连起来。

**用故事反转做节奏（不加贴纸）**
- 分句时把「Then one night,」单独成句，给反转前留一拍。
- 「by accident」和「on purpose」是一对反义：说到 on purpose 时，卡片左边淡显 by accident，箭头指向高亮的 on purpose。没有新增任何文字。
- 从「Now, I push it off on purpose.」开始，底片以脸为中心在 1.1 秒内缓推 6%，保持到片尾。只动底片，文字层不动。
- 段落之间留干净画面，等于四次“换气”。
- 第33期大部分句子变成一行中文后，地板上的玩具老鼠在字幕下方露出来了。说到“故意推下去”时，观众能看到那只老鼠就在地上。

**分句（第33期）**：14 句改为 17 句，只在中英文都有逗号、语序一致的地方拆（第1、2、9句各拆成两句）。没有改任何字词，英文逐词等于 `english.txt`，中文逐字等于 `chinese.txt`。

### 方案A「上学下讲」（推荐）
- 上方是学习栏：提示条、气泡、原题、表达卡都在这里。中间是 Evan，全身不遮。下方是字幕。
- 字幕不用底板，用一圈羽化暗晕加 3px 深色描边和投影。暗晕强度逐句自适应：字下背景偏亮时自动加深，直到白字对底色的对比度达标。
- 第33期平均遮盖从 28.5% 降到 13.9%。
- 代价：卡片和字幕分在上下两端，视线要移动。我用“字幕里已经有中文释义高亮”来抵消，卡片变成强化记忆而不是必读。

### 方案B「贴字幕小标签」（保守）
- 字幕保留底板，换成暖棕色半透明。
- 表达变成一行小标签（序号 + 英文 + 中文），贴在字幕正上方。视线不离开下三分之一。
- 上方只有提示条、气泡和原题，原题可以紧跟气泡出现（第33期 2.95 秒）。
- 代价：小标签会盖到一点爪尖；by accident → on purpose 的成对卡在这个版式里没有；整体更接近旧版的“框”感。
- 第33期平均遮盖 12.5%。

### 可选项：片尾七表达回顾
`out/ep33-A-recap/sample.mp4`。口播结束后把最后一帧虚化压暗，停 3.6 秒，显示七组表达清单。口播和正片部分与方案A完全相同，但**片长从 40.1 秒变成 43.7 秒，尾部无声**，所以默认关闭，需要你审核后才用。

### 我的建议
用方案A。它对“看点、主体、道具、反转”四件事的改善最直接，四期素材上都通过了检查。如果你看片后觉得上下视线移动不舒服，方案B是同一套代码换一个预设。

### 主观设计判断（我的看法，没有数据支撑）
- 开场用气泡提问比题目面板更能让人看懂看点。
- 奶油色 + 可可棕 + 黄色记号笔比深蓝面板更贴“温馨、小金渐层”。
- 上学下讲的空间分工容易被观众学会；卡片离字幕远但不影响理解。

- 不做逐词卡拉 OK：更热闹，但和“字幕更舒服”冲突，而且会暴露识别误差。

- **手机上的实际可读性**：我只做了缩到 390px 宽的静帧，没有在真机上看。
- **开场钩子、片尾回顾对收藏的作用**：都是假设。
- **没验证的**：听感、口型、推近的实际动态观感、提示条里 28px 小字在真机上是否够清楚。

## 6. 代码与运行

### 每期要写的配置（`subtitles.v2.json`）
在原 `subtitles.json` 基础上多了这些，都可选：

| 字段 | 作用 | 不写时 |
|---|---|---|
| `hook.text` | 开场气泡文字 | 取 `draft.json` 的 `cover`；写 `"hook": false` 关闭 |
| `story.twist_at` | 反转句开头的英文，从这句开始缓推 | 不推近 |
| `story.pairs` | 成对展示的表达，如 `[["by accident","on purpose"]]` | 不成对 |
| `story.bookend` | 最后一句时气泡是否回来 | 回来 |
| `safe.face` | 脸部安全框 `[x0,y0,x1,y1]` | 每次自动估计并提醒你固定下来 |
| `question_at` | 强制指定原题展开的时间 | 自动找空档 |
| 句内 `zh` 里的 `\n` | 指定中文断行 | 自动断行 |
| 句内 `zh_hl` | 指定中文里要高亮的词 | 自动用表达的释义去匹配 |
| `header.title_en` | 原题，不用再手动换行 | — |

没有 `subtitles.v2.json` 时工具直接读原来的 `subtitles.json`，所以旧格式也能跑。

### 用到新一期上
新一期走完原流程、拿到原片和识别缓存后，把素材放成和 `episodes/33/` 相同的结构，在 `experiments/redesign-v2/episodes/<期号>/` 写一份 `subtitles.v2.json`，然后 `detect-safe → check → sheet → render`。也可以用 `--episode-dir` 指向任意素材目录。

这套工具**不做语音识别**，换了音频仍需用生产流程生成 `asr-<原片SHA256>.json`。它也**没有接入**生产适配器 `evan_render.finish()` 的回执和防覆盖逻辑，目前只是并行的实验入口；确定方案后再接。

## 7. 另行建议（涉及内容或前期，未实施，先请你审核）

这些会影响稿件或出图，不属于本轮后期改动：

1. **写稿时错开表达**：两个重点表达尽量不放在同一短句里、间隔不少于约 2.5 秒；第一个表达不早于约 2.5 秒。这样卡片不用并排，开场气泡也不用和首卡抢位置。第31期前 13 秒有 4 个表达，是最挤的例子。
2. **笑点句后留一口气**：第33期最后一句说完到片尾只有约 0.5 秒。如果 HeyGen 原片尾部能多留 0.8—1 秒静止，笑点和片尾呼应会更从容。
3. **场景图给版式留位置**：猫头顶上方约 150—480px 保持干净的墙面或背景（放学习栏）；关键道具不要落在 y≈1340—1640 的字幕区，或者像第33期这样放在更靠下的位置。这只是给出图提示词的参考，图仍由你审核。
4. **卡片弹出音效 / 轻 BGM**：可能增加节奏感，但会改变音轨，本轮为保持“同一配音”没有做。
5. **发布前修两处已确认内容的小问题**：第30期「Recently,I」的空格、第31期中文字幕与 `chinese.txt` 的差异。

## 8. 已知局限

- 脸部框是按“整片最大活动区域”估的一个固定矩形，适合现在这种固定机位、头部基本不动的底片；如果以后底片里猫头大幅移动，需要重新考虑。
- 中文断行没有分词库，非标点处的自动断行靠规则，报告会列出来让人看；第33期和第30—32期目前都没有触发。
- 方案A 的上方栏在“脸很靠上”的图里放不下标准卡时会自动换小标签，再放不下会报错并建议改用方案B。四期素材都没有走到报错。
- 自适应暗晕用 1 秒处的一帧代表字幕区背景，前提是机位固定。
- 对照视频为了并排缩到了每边 720×1280，看细节请看单独的样片。
