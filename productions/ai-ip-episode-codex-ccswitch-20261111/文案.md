# 本期口播文案（用户确认稿）

C盘爆满不敢乱删？只发一句话，AI 就帮你清除垃圾，把大文件挪去其他盘。

普通网页 AI 只能陪聊，而 Codex 能直接在你电脑里动手干活。

没有账号也别慌，只需三步，就能给它换上几块钱就能用的 DeepSeek 大脑。

第一步，浏览器搜Codex，进官方入口下载安装；再搜 CC Switch，进官方入口下载对应系统的版本。

第二步，打开 CC Switch，点顶部第三个 OpenAI 图标，点加号选 DeepSeek。直接点右下角“获取 API Key”，在后台充几块钱、新建密钥复制回来，粘贴进去点添加。

第三步最关键：去 CC Switch 左上角设置里，打开本地路由总开关。最后再重开 Codex，右下角显示 DeepSeek 就连上了！左下角设置里还能一键调成简体中文。
