## 这是什么工程

竖屏教程片，1080×1920，30fps，约 64.3 秒。账号名「阿泽」。合成是 Remotion 4.0.542，入口是 `comp/render.mjs`，成片组件 id 为 `Film`。

结构（不要轻易推翻，除非用户要求）：

- 0–18.3 秒钩子：上半区大字和图形，下半区数字人卡片（约占画面 1/4）；14.2 秒起录屏以小卡片出现再长大

- 54–64.3 秒贴士和片尾：数字人回到大卡片

视觉：暖纸白底、墨色线框加硬投影、朱红强调色。底部约 316 像素是深色底栏。数字人卡片上有「AI 数字人」标识。

## 怎么出片

在 `comp/` 下：

```bash
npm install
node render.mjs --stills 0,1.5,3,21.8,40.9 --out ../build/stills
node render.mjs --video ../build/raw.mp4
```

`render.mjs` 只出无声画面。合入口播、响度、手机预览、拼图、SRT、质检，用 `tools/finish.sh v002`。口播音轨优先取自 `audio/F_vo.m4a`（本包已提供），只做响度标准化（目标约 -14 LUFS），不要重配音、不要变速口播。

注意：

- `package.json` 已写好可在本机安装的依赖。**不要**去使用 Linux 工作站上的 `node_modules`，其中有 Linux 专用的 Remotion compositor。本机 `npm install` 会安装对应系统的组件。
- `render.mjs` 里默认找 `/usr/bin/google-chrome`，在 Windows / macOS 上请改成本机 Chrome，或让 Remotion 用它自己的浏览器。可用环境变量 `CHROME`。
- `finish.sh` 是 bash，拼图那一步写了 Linux 字体路径 `/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc`。在 Windows 上用 Git Bash，或改成这台机器上的字体和等效命令。逻辑保持不变：不覆盖旧版本。
- 改字幕和标注在 `comp/src/data.ts`；改取景和镜头在 `comp/data/edit.json`；改版式在 `comp/src/` 各组件（`Hook.tsx`、`Stage.tsx`、`Human.tsx`、`Steps.tsx`、`Outro.tsx`、`ui.tsx`）。
- 上屏口播文字必须与 `文案.md` 逐字一致。`tools/qa_text.mjs` 会比对，不一致不要当作成片。
