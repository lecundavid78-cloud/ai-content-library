# 群文案：三步给 Codex 换上 DeepSeek（一步一图）

> 发群顺序：先发这段开头文字，再按编号 00 → 12 依次发 13 张图，每张图后面跟对应的那段话。图片都是 1080 宽，手机上直接看、能保存。

**开头（先发）**

视频里说的配套教程来了 👇
三步给 Codex 换上 DeepSeek，几块钱就能用。一共 13 张图，跟着点就能做完。
准备好：一台 Windows 或 Mac 电脑，一个 DeepSeek 开放平台账号。

---

**图 00｜`00_封面.png`**

三步：① 下载 ② 加 DeepSeek ③ 开路由。

**图 01｜`01_第1步_下载Codex.png`**

第 1 步。浏览器搜 Codex，进 Codex 官方下载页，点「下载 Windows 版」，下载完双击安装。别点来路不明的下载站。

**图 02｜`02_第1步_下载CC_Switch.png`**

再搜 CC Switch，进 CC Switch 官方下载页，点「Download Now」，按自己的系统选 Windows 或 macOS，下载后安装。

**图 03｜`03_第2步_打开CC_Switch点加号.png`**

第 2 步。打开 CC Switch，点顶部第三个图标，再点右上角的橙色加号。

**图 04｜`04_第2步_选DeepSeek获取Key.png`**

在列表里选 DeepSeek，然后点「获取 API Key」，会跳到 DeepSeek 后台。

**图 05｜`05_第2步_充值并新建密钥.png`**

在后台充几块钱，再新建一个密钥，马上点「复制」。
⚠️ 密钥只显示一次，自己存好，别发给任何人，也别截图发群里。

**图 06｜`06_第2步_粘贴并添加.png`**

回到 CC Switch，把密钥粘贴到 API Key 那一栏，显示成一串圆点就对了，然后点右下角「添加」。

**图 07｜`07_第3步_进入设置.png`**

第 3 步，最关键。先确认列表里已经有 DeepSeek，再点左上角「CC Switch」右边的小齿轮进设置。

**图 08｜`08_第3步_打开路由总开关.png`**

切到「路由」，展开「本地路由」，把「路由总开关」打开。

**图 09｜`09_第3步_确认启用并勾选Codex.png`**

弹出提示就点「我已了解，继续启用」。然后在「路由启用」里把 Codex 的开关打开。

**图 10｜`10_第3步_检查开关.png`**

看到顶部提示「Codex 路由已启用」，Codex 开关是绿的，就开好了。哪个不是绿色，回去再点一下。

**图 11｜`11_第3步_重开Codex看到DeepSeek.png`**

把 Codex 关掉再打开，输入框右下角显示 DeepSeek，就连上了！（图是示意，以你电脑上的实际界面为准。）
