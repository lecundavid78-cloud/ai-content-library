### 推荐拍摄路线（给国内 AI 初学者视频）

**推荐：路线 A + D 的「演示向」组合，不首推纯赞赏暴利叙事。**

**理由（有证据支撑）：**

1. **效果可见**：歸藏/路飞有可下载 GIF 成品；Gorden_Sun 有「参考图 ↔ 结果」同帖对比。

3. **交付可讲**：杰哥/麻酱文章写清微信投稿规格、含义词、赞赏开关；Ray skill 把「客户交付包」产品化。
4. **变现须克制**：黄啊码截图里高赞赏专辑「最后更新」为 **2025-09**，评论质疑「和 GPT 无关」；作者自称「分享思路」、此前用过**即梦**。blune66 反证：多套已上架赞赏多为 `-`。闲鱼/小红书「9.9 接单」多为**作者声称/观察**，本轮未见订单截图。

**建议视频主线：**  
「一张角色母图 → ChatGPT Images 2.6 逐张 GIF → 压到微信规格 →（可选）闲鱼定制报价演示」；微信赞赏作「可选渠道 + 真实门槛」，不要做成「一上架必赚千元」。

## 3. 制作方法比较（针对视频关心点）

### 角色/衣服/画风一致

- **有效做法（有帖）**：固定上传同一张母图；提示词写死发型、配色、标志道具、Q 版比例（歸藏、路飞、Ray skill、杰哥）。
- **失败信号（有帖）**：拉高帧数到 30，人物漂移、清晰度下降（歸藏评 Sleep4993）。
- **IP 细节**：麻酱称肉垫颜色会被模型画错，需人工盯。

### 中文配字 / 动作 / 透明底 / 边缘

- **配字**：提示词要求 2–8 字、顶部粗圆体+描边、不挡角色（歸藏/路飞）；或「不要文字」后期自己加（杰哥示例）。
- **动作**：要求「一个核心笑点 + 首尾可循环」。
- **透明底**：**多帖承认是痛点**。纯白底易做；透明需抠图/技能脚本。hppzyy：不透明 PNG 会被拒。Ray/wechat.md：封面图标要透明底。
- **聊天小尺寸清晰度**：杰哥要求压到 240 后自检；本轮**无人提供「聊天气泡实拍对比」系统证据**。

## 4. 推荐演示路线（完整步骤）

**目标交付物**：8 张动态 GIF（可先演示 3 张）+ 说明如何变成微信投稿包；可选展示「宠物定制报价页」概念。

### 输入

- 一张**自有版权**角色图或宠物照片（勿用未授权 IP / 大肥鱼若声明非商用则勿商用）。
- ChatGPT 账号且已开通 Images 2.6 GIF（以你账号实际入口为准；本轮多例证实网页可用、Codex 曾不可用）。

### 步骤

1. **定母图**  
   - 有角色图：直接用。  
   - 仅照片：先让模型转成统一 Q 版角色图（Ray `character` 或口头「做成统一卡通形象」）。  
   - **验收**：用户确认五官/配色/服装。

2. **锁定提示词模板（推荐歸藏完整版）**  
   见第 5 节。每次只改最后一行「表情包主题」。

3. **逐张生成（严格顺序）**  
   - 建议主题示例：收到 / 在改了 / 哈哈哈 / 谢谢 / 下班 / 救命 / 贴贴 / 晚安。  
   - 每张：上传同一母图 + 模板 + 主题。  
   - **缺失（原帖未统一给出）**：官方是否支持「一次出 8 张独立 GIF」；多数实操仍是逐张。

4. **质量闸**  
   - 角色是否漂；字幕是否糊；循环是否跳。  
   - 失败：改主题重抽，或降低动作复杂度；勿盲目加帧。

5. **规格化（微信向）**  
   - 压到 **240×240、≤500KB、可循环**。  
   - 需要透明：抠白底（工具：**多数教程未点名**，可标「缺失/用 skill build」）。  
   - 另备：封面 240 透明、图标 50、横幅 750×400（无字）。

6. **（可选）投稿**  
   - sticker.weixin.qq.com → 个人注册 → 动态表情专辑 → 含义词 ≤4 字 → 勾选赞赏（需艺术家资料）。  
   - **不要承诺过审与收入**。

7. **（可选）产品化**  
   - 闲鱼/小红书：卖「宠物/本人卡通定制」，交付 zip；参考 Ray custom-order（报价数字仅作者声称）。
