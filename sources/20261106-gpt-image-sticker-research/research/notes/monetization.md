# 表情包变现路径核对（个人/宠物 · 品牌 · 微信平台）

**核查日期：** 2026-11-06（Asia/Shanghai）  
**原则：** 收入数字必须标明证据等级；禁止编造成交额或伪造结算截图。官方规则与博主自述分开写。

**证据等级：**

| 等级 | 含义 |
|------|------|
| A 官方 | 微信/腾讯开放平台公开页面或协议原文 |
| B 一手公开自述 | X/小红书等作者自称，有帖可核，但无独立审计 |
| C 二手教程/媒体 | 攻略站、媒体转述报价或「月入」故事 |
| D 想法/假设 | 未声称已成交，或仅市场观察语气 |

---

## 一、路径总览（先讲结论）

| 路径 | 谁付钱 | 交付通常是什么 | 本轮证据可靠度 | 视频建议 |
|------|--------|----------------|----------------|----------|
| A. 个人/宠物定制代做 | 个人买家（自己、情侣、宠物主） | PNG/GIF 套图 + 可选切好投稿包；有时代上传 | **B+C**：有公开报价与「有人在做」观察，**无**本轮核到的支付流水 | **值得讲机制与交付物**；报价只作「市场常见说法」并标注来源帖 |
| B. 商家/品牌角色定制 | 商家、机构、IP 方 | 品牌形象表情 + 授权条款；常要求发票/对公 | **C/D 为主**：公开「企业价」多为教程建议价；真实合同鲜少公开 | 可讲需求差异与合规风险；**不要报未证实的客单价当事实** |
| C. 微信表情开放平台上传 + 赞赏 | 终端微信用户自愿赞赏 | 免费下载表情；赞赏为打赏非卖断 | **A 机制清晰**；**单套「赚多少」无官方均值**；种子帖「超千元」= B 自述 | **优先讲官方规则与规格**；收入只引用可核帖并标明「作者自称」 |

**推荐讲法（证据可靠）：**

1. 先演示「能做出符合规格的一套文件」；  
2. 再讲三种变现**谁付钱、买到什么**；  
3. 微信路径只承诺「可能收到赞赏」，不承诺「躺赚/月入」；  
4. 凡金额必带出处与日期，并说「未核验到账」。

## 二、路径 A：个人 / 宠物定制

### 2.1 谁付钱、为什么、买什么

- **付款方：** 想要「自己的脸/自家猫狗/情侣形象」卡通表情的个人。  
- **动机：** 聊天辨识度、礼物感、社交炫耀；不是买「上架权」。  
- **常见交付（综合公开教程与种子帖观察，非官方标准合同）：**  
  - 16–24 张静图或动图；  
  - 透明底、统一角色；  
  - 有时含封面/横幅/图标等投稿素材；  
  - 源文件或仅成品；修改次数需合同写明。

### 2.2 客户从哪来、报价说法

| 来源说法 | 等级 | 备注 |
|----------|------|------|
| @wangray 2026-11-05：小红书、闲鱼已有人接定制；「一单 9 块 9」「搞定的 2、30 都有」 | **B（市场观察口吻）** | [原帖](https://x.com/wangray/status/2118332972659245163)；**不是**附支付截图的成交审计；「2、30」语义更像接单量级自述/观察，宜在视频说「作者称」 |
| 开源 skill 仓库 ray-sticker-shop 指向「一张照片→一套」工作流 | **B 产品/工具** | GitHub 公开；证明「交付流程可产品化」，**不证明**收入 |
| 攻略站常见报价区间（如数十至一两百元/套、企业更高） | **C** | 多为作者建议价；本轮**未**逐条核验订单 |

### 2.3 成交 vs 报价 vs 想法

- **实际成交（本轮）：** 未取得买家付款记录、闲鱼订单号或聊天脱敏流水 → **不能**写成「已证实均价 xx」。  
- **展示报价 / 作者说法：** 9.9 元等 → 标 B。  
- **想法：** 「接几单回本 ChatGPT 会员」→ D/营销话术，可作讨论点但勿当财务建议。

### 2.4 成本（可知部分）

- ChatGPT 订阅：官方 Plus $20/月等（见 `official-model.md`）；生图占用套餐额度，**无**官方「表情包专用成本」。  
- API：按 token，张均成本需实测。  
- 若收入含卖课/卖提示词：种子帖主推赞赏与接单，**未**在本轮核到该两帖的卖课分成数据。

## 三、路径 B：商家 / 品牌角色定制

### 3.1 结构

- **付款方：** 商户、餐饮/美业门店、MCN、游戏/IP。  
- **为什么：** 私域运营、客服话术、活动传播；常要 **商标/形象授权** 与修改权。  
- **买到什么：** 角色设定 + 一套表情 + 使用范围（仅微信 / 含海报等）+ 修改轮次；对公可能要合同与发票。

### 3.2 证据情况

- 公开「企业 800–2000 元/套」等数字多见于 **C 类攻略**，本轮**未**核到附合同金额的一手品牌案例。  
- 微信官方对 **推广类** 表情有专门规则：免费表情允许推广类但**不在商店展示**（仅可搜/下载）；付费/特效若属推广类则不能过审或下架（见平台指南 FAQ，等级 A）。  
- **真人/艺人截屏表情**有粉丝/指数门槛（等级 A，[`guide/real`](https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=guide%2Freal)），普通人「品牌吉祥物卡通」通常走「卡通表情或其它」，但仍须原创或授权。

### 3.3 视频建议

- 讲清：**品牌单 ≠ 随便用名人脸**；需授权。  
- 报价只说「公开教程有人建议企业价高于个人定制」，**不要编平均客单价**。

## 四、路径 C：微信表情开放平台上传与赞赏

### 4.1 谁付钱、买到什么（A 官方）

- 用户**免费下载**表情使用。  
- **赞赏** = 用户自愿赠与，表达喜爱；**不是**标价卖表情文件。  
- 开通赞赏后，资金经微信支付渠道到达创作者绑定账户（个人→微信零钱；企业→商户号）。  
- 腾讯**不对**下载量或最终所得作承诺（赞赏协议 4.3.5）。

**主要官方 URL（核查日 2026-11-06）：**

- 平台入口：https://sticker.weixin.qq.com/  
- 指南（SPA，含制作规范/FAQ）：https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=guide%2Findex.html  
- 赞赏协议：https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=deal%2Freward  
- 企业商户号绑定说明：https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=faq%2Fenterp  
- 截屏/真人指南：https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=guide%2Freal  

### 4.2 入驻与账号（A）

- 支持**中国大陆**身份的个人与企业注册（指南 FAQ）。  
- 个人：权利主体个人；赞赏进绑定微信号零钱。  
- 企业：须绑定**同主体**微信支付商户号；商户号**费率 ≥ 1%**；暂不支持个体工商户注册企业账号（企业 FAQ）。  
- 开通赞赏条件（指南）：① 艺术家资料审核通过；② 个人绑定微信号且满足收款要求 / 企业绑商户号；③ 账号无违规；④ 提交时上传合格赞赏引导语、引导图、缩略图；⑤ 同意赞赏协议。

### 4.3 上传规格（A — 摘自平台指南前端 JS 构建 `sticker_platform/26052800`，2026-11-06）

**表情专辑素材表（当前表字段名「表情图」等）：**

**补充细则（同指南文案）：**

- 同一套专辑须**全动态或全静态**，不可混用。  
- 详情页横幅：避免出现任何文字；避免透明底（文案含「避免使用透明背景」）。  
- 封面图 / 聊天图标：建议半身或全身（封面避免纯头）；**不应有白色描边**、避免锯齿；须透明背景；避免白底。  
- 含义词：≤4 汉字；名称等另有字数限制（指南）。  
- 赞赏引导图：GIF 或 PNG，**750×560**，≤500KB；避免透明底。  
- 赞赏致谢图：GIF 或 PNG，**750×750**，≤500KB；避免透明底。  

**与旧教程差异（必须在视频提醒）：**

- 网上大量旧文写主图 **≤100KB**、缩略图 120×120、强制 16/24 张、强制 2px 白边等——**与本轮官方 SPA 表不完全一致**。  
- 2015 公告「表情单品」曾写主图 GIF 240 **≤100KB** 等，属历史单品规则，**不能**直接当成 2026 专辑规则。  
- 本轮 SPA 专辑表**未列出**独立「表情缩略图」行；若上传表单仍索要缩略图 → 标 **待核（以上传页为准）**。

### 4.4 审核（A）

- 须符合《微信表情制作规范》与《微信作品审核标准》。  
- 通常约 **5 个工作日**内反馈（排队视投稿量）。  
- 待审/驳回/通过可改；**已上架**每月限改 1 次，改后重审。  
- 必须原创或拥有版权；禁止多项违法违规内容；推广类判定见 FAQ。  
- 使用 emoji 素材二次创作的作品**不能开通赞赏**（指南文案）。  
- 涉及肖像须证明与授权。

### 4.5 AI 生成内容（官方）

- **本轮在指南 JS / 赞赏协议 / 企业 FAQ / 真人指南中，未找到单独条款写「禁止 AI」或「允许 AI」。**  
- 已证实约束是：**原创或合法授权**、不侵权、符合审核标准。  
- 因此视频安全表述应为：  
  > 平台未单独公示「AI 白名单」；用 AI 仍须保证你对成图享有权利或授权，且画面不侵权、符合规格与审核标准。是否过审以审核结果为准。  
- 第三方文章声称「AI 可上架」= **C**，不能替代官方条款。

## 五、成本与「卖课」边界

- **工具成本：** ChatGPT 订阅或 API token——官方有价；表情包项目分摊需自测。  
- **时间成本：** 生成、修边、压到 240 与 500KB、过审驳回重提——官方无标准工时。  
- **卖课 / 卖提示词 / 卖 skill：** 与「表情赞赏」「定制费」是不同收入桶；两则种子帖未提供可审计的课程收入拆分 → 视频若提到，须分开标注「未证实」。

## 六、视频可用结论（短）

1. **机制最硬的是微信官方：免费下载 + 可选赞赏 + 严格规格/审核。**  
2. **定制代做**逻辑清楚，但公开价格多为自述或攻略，适合讲流程不适合讲「稳赚」。  
3. **品牌单**合规与授权权重更高，缺公开成交样本。  
4. **禁止**使用未核实的「月入」「超千元保底」「官方分成 xx%」；「超千元」仅可作某作者 2026-11-05 自述并注明未核到账。

## 七、待核问题（给后续拍摄）

1. 实际上传表单是否仍要「表情缩略图」及现行尺寸。  
2. 主表情图是否仍有「必须白描边」的后台校验（当前 SPA 封面/图标要求无白描边）。  
3. 赞赏「渠道技术服务成本」当前实际比例（个人）。  
4. AI 成图过审的驳回理由样本（需真实后台截图，勿伪造）。  
5. 闲鱼/小红书真实成交价分布（需脱敏订单，非口头）。  
6. 种子帖「超千元」的时间窗、是否含非赞赏收入。
